# 处理流程方案

| 环节 | 动作 | 默认 | 学生介入 |
| --- | --- | --- | --- |
| 汇入 | 上传 / 聊天导入 / 相册 | 学生发起 | 选择来源渠道 |
| 解析 | OCR、ASR、页级切片 | 系统自动 | 仅失败项 |
| 整理 | 课程、类型、章节聚类 | 系统自动 | 置信度 < 0.85 |
| 来源评级 | 教师 / 本人 / 同学 / 不明 | 系统自动 | 「真题」「重点」敏感标签 |
| 冲突对齐 | 多源对照 | 系统自动检出 | 选择采信源 |
| 二创 | 提纲、闪卡、真题包 | 系统自动且强制引用 | 抽查；剔除无出处句 |
| 共享 | 小组权限 | 学生发起 | 系统禁止去掉未核验警告 |

原则：不给每份文件打标签；学生只处理会导致误信的节点。
