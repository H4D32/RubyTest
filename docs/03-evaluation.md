# 评测方案与投入门槛

## 评什么

- 整理：分类、来源、去重、章节。
- 采信：低置信是否入队、真题误标、冲突召回。
- 二创：引用可验证、无源幻觉、与课件一致性。

## 怎么评

1. 单课 30–50 份真实资料金标（含来源不明与冲突件）。
2. 自动指标 + 20 分钟学生任务评测。
3. 弃用测试：混入与课件矛盾的生成句，漏到复习包即门禁失败。

## 门槛（同时满足才允许自动生成默认真习包）

- 高置信分类准确率 ≥ 90%
- 生成条目可溯源率 ≥ 95%
- 无源幻觉率 < 5%
- 冲突漏检率 < 10%
- 每 20 份资料确认 ≤ 5 次，单次 < 20 秒
- 含确认到可用包 < 15 分钟
- 任务后 ≥ 70% 表示会用于下次考试

信任指标不达标时，禁止自动二创发布。
