# 产品定位说明：溯知

## 核心问题

大学生并不缺文件，缺的是一条在「不愿打标签」和「不敢误信」同时成立时，仍能把相册、聊天、网盘里的课件、真题、笔记、录音变成**可追溯、可核对、可复习**材料的链路。

一旦整理稿与原课件对不上，用户会整套弃用。因此产品的核心不是摘要文采，而是采信。

## 成立判据

1. 考前存在多源、未分类的真实整理任务。
2. 自动处理覆盖高置信文件，确认次数远低于手工归档。
3. 每条二创语句可回到原文；冲突被拦截。
4. 平台已有的多模态能力足够做页级引用。
5. 相对「网盘 + 通用对话模型」，节省的是核对成本而非存储成本。

任一信任指标失败，则产品不成立，只应提供资料库，不应自动生成默认真习包。

## 主张

高置信自动落库；真题来源、作者不明、跨源冲突必须学生确认；复习包强制带出处；协作时原始文件与二创权限分离。
