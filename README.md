# 溯知 · 大学生学习资料管理原型

面向考前可用的资料消费：上传 → 自动整理 → 只确认不敢信的项 → 产出带原文锚点的复习包。

## 本地运行

```bash
cd app
npm install
npm run dev
```

打开提示的本地地址。从「演示」走完《操作系统》示例资料全流程。

## 产出物

| 页面 | 内容 |
| --- | --- |
| `/` `/positioning` | 产品定位与成立判据 |
| `/flow` | 处理流程与系统/学生分工 |
| `/demo` | 可交互原型 |
| `/eval` | 评测方案与投入使用门槛 |
| `/sharing` | 协作共享与权限 |

独立文档见 `docs/`。
