# 交付三：评测方案 — 玩法是否值得继续投入 × 生成世界表现

**产品：**《我的AI小岛》  
**回答题目两问：**（1）这一玩法值不值得继续投入；（2）生成世界的表现如何衡量。  
**评测重心（与交付一对齐）：** 回访一致性 + 连续编辑 + 生成性能。经济与付费为观察项，**不作为早期止损主闸**。  
**Demo 口径：** 预设物模拟生成、前端/本地状态模拟持久化；本方案中的离线指标是「真实能力核验清单」，不要求 Demo 当场跑满。

---

## 〇、对本稿评测设计的评审结论（阅卷前先自检）

原方案**方向正确，能评到题眼**，但有几处会评错对象或过早用商业指标杀死玩法。交付三已按下面结论改过。

| 原设计 | 判定 | 处理 |
|---|---|---|
| 双问题（投入决策 + 世界表现）+ 命门量化 + 分阶段门槛 + 可复用框架 + 躲猫猫渐进路径 | **恰当** | 全部保留 |
| 持久化率 / 位置准确率 / 多轮编辑累积一致性 / 幻觉率 | **恰当** | 保留；补「允许演变 vs 非法漂移」 |
| 经济通胀、付费转化、ARPU 作为灰度/全量硬门槛 | **不恰当（早期）** | 降为观察项；阶段 0–1 不因付费停投 |
| 实验组=AI+持久化 vs 对照=仅预设 | **混淆因果** | 改为三臂：预设 / 可生成但不持久 / 生成+持久+可再编辑 |
| 采信率越高越好、编辑率高=生成差 | **过度解释** | 改成组合解读，设健康区间 |
| NPC 记忆 85% 一刀切 | **颗粒度不够** | 拆成「世界事实记忆」与「对话风味记忆」 |
| 持久化测试=关会话清缓存 | **可能测不到真持久** | 规定离开操作：新会话 + 清前端缓存 + 重载世界状态源 |
| 两套阶段（0–3 投入门 vs A–C 能力验证）易打架 | **结构风险** | 合并映射：A⊂阶段0 生成子集；B=阶段0 命门；C=阶段1 起完整形态 |
| 只测「不变」 | **漏掉题目「世界演化」** | 增加：已确认资产不变率、演化可解释率、未确认不得写入率 |

**总评：** 用这套「命门指标 + 分阶段止损 + 先单局再持久」可以正确判断值不值得投入；必须把**世界表现**定义成「该变的按规则变、不该变的回访仍在」，而不是世界冻死。

## 一、评测目标

四层机制：**离线能力核验 → 一致性与连续编辑自动化 → 在线体验 → 长期价值观察**。

1. **值不值得继续投入：** 分阶段量化门槛，不达标则停或转方向（优先转向不依赖跨局记忆的生成玩法）。  
2. **生成世界表现怎么衡量：** 先回答三个生死问题——玩家用 AI 创造的东西，离开再回来，**还在不在、对不对、能不能继续改**；再衡量生成是否可用、世界是否在规则内演化。

---

## 二、指标体系

### 第一层：生成世界表现（命门）

| 维度 | 指标 | 定义 | 评测方式 |
|---|---|---|---|
| **生成能力** | 生成成功率 | 固定用例集上产出可放置结果的比例 | 自动化，≥1000 次，**用例覆盖风格/材料/编辑指令，禁止纯随机刷数** |
| | 延迟 P50/P95 | 从确认发起到可预览 | 性能压测 |
| | 描述符合度 | 结果与指令匹配 | 抽样人工双评（≥200），第三人仲裁 |
| **回访一致性** | 物品持久化率 | 离开后再进入，已确认物品仍存在 | 自动化：写入 → **新会话+清前端缓存+重载状态源** → 对照 |
| | 位置/姿态准确率 | 坐标、旋转与离开时一致（容差需预先规定，如位移 <1% 场景尺度） | 自动化 |
| | 属性保持率 | 颜色/尺寸/材质/编辑记录不丢 | 自动化 |
| | NPC 世界事实记忆准确率 | 是否记得「谁、在哪、放过什么已确认物」 | 自动化为主 |
| | NPC 对话风味记忆准确率 | 闲聊要点、送礼等 | 自动化 + 人工；**低于事实记忆门槛不单独否决立项** |
| **连续编辑** | 编辑成功率 | 对已写入物改颜色/大小/局部重绘且提交成功 | 自动 + 人工 |
| | 多轮编辑累积一致性 | 5/10 轮后物体仍可识别、属性不丢、未声明部分未重骰 | 压力测试 |
| | 编辑后回访保持率 | 编辑效果经离开再进入仍在 | 自动化 |
| | 身份保持率 | 多轮编辑后仍被判为「同一物体」（非换成另一资产） | 自动特征/人工抽检 |
| **世界合法演化** | 已确认资产不变率 | 规则允许的演变（季节、NPC 走位、植物）**不得改写**已确认外观与位姿 | 自动化对照快照 |
| | 演化可解释率 | 可见变化能在事件日志中找到对应规则 | 抽检 |
| | 未确认写入泄漏率 | 未点确认却进入正式世界的次数 / 生成次数 | 埋点，目标 **= 0** |
| | 幻觉率 | 与已有世界矛盾（叠放占用、凭空材料、否定已有物） | 自动 + 人工 |
| | 快照完整率 | 每次正式状态变化后快照成功且可回滚 | 监控 |

**命门否决（阶段 0）：** 物品持久化率 <95%，或 10 轮编辑累积一致性 <90%，或未确认写入泄漏率 >0（抽测），则玩法在技术上不成立，不进入「做完整小岛」的投入。

### 第二层：玩家是否买账（体验）

| 维度 | 指标 | 定义 | 注意 |
|---|---|---|---|
| 信任 | 回访一致性主观认同率 | 回访后认同「东西都在、和走时一样」 | 问卷，配合客观持久化，防自欺 |
| 信任 | 不一致报告率 | 主动报「没了/不对」 | 越低越好；为 0 也要抽检，防不会报 |
| 信任 | 回访弃玩率 | 回访发现不一致后当日不再登 | **体验层最硬指标** |
| 生成交互 | 首次确认率、编辑后确认率、放弃率、重生成次数 | 行为埋点 | **不要单看采信率：** 首次确认高可能是懒点；健康形态是「可首次过 + 愿编辑再确认」 |
| 生成交互 | 编辑率 | 对预览做调整的比例 | 过高暗示指令符合度差；过低可能预览不可改或玩家不敢改；看区间而非单边 |
| 留存 | 单次时长、次日/7 日留存 | 产品数据 | 必须结合 A/B 三臂解读 |
| NPC | 对话「记得我」认同率 | 问卷 | 交易完成率仅观察，**不作为阶段 0–1 门槛** |

### 第三层：是否值得加码投入（价值，早期降权）

| 维度 | 指标 | 角色 |
|---|---|---|
| 创造活跃 | 日均确认写入次数、日均编辑次数、周回访次数 | 阶段 1 起作为「有人在塑世」的证据 |
| 经济健康 | 通胀、NPC 收购波动、材料消耗 | **长线观察**；完整经济未进 Demo，阶段 0–1 **不设停投线** |
| 商业化 | 转化率、ARPU、30/90 日留存、NPS | 阶段 2 末–阶段 3 参考；**禁止用付费转化率否决阶段 0 技术验证** |

## 三、评测方法

### 3.1 离线（上线前 / 阶段 0 必做）

| 测试项 | 方法 | 样本量 | 通过标准 |
|---|---|---|---|
| 生成能力 | 固定用例集批量请求 | ≥1000 | 成功率 ≥90%；P95 ≤8s |
| 持久化 | 写入 N 物 → 新会话 + 清前端缓存 + 重载状态 → 比对存在/位姿/属性 | ≥100 物 ×10 轮 | 持久化率 ≥95%；位置准确率 ≥95% |
| 多轮编辑 | 同物 10 轮编辑，查崩坏、丢属性、身份丢失 | ≥50 物 ×10 轮 | 累积一致性 ≥90% |
| 门禁 | 随机取消/超时，断言正式世界无该资产 | ≥200 次 | 泄漏率 = 0 |
| 合法演化 | 推进季节/NPC 作息后比对已确认资产 | ≥50 场景 | 已确认资产不变率 ≥99% |
| NPC 事实记忆 | 放置/对话脚本后提问「岛上有什么」 | ≥20 NPC × 脚本 | 事实记忆 ≥90% |
| NPC 风味记忆 | 闲聊要点 | 同上 | ≥85%（观察） |
| 幻觉 | 在已占用世界批量生成 | ≥500 | 幻觉率 ≤5% |

### 3.2 在线（灰度）

**三臂 A/B（至少要能区分「生成」和「记得住」）：**

| 臂 | 体验 | 用来证明什么 |
|---|---|---|
| A 预设 | 只能用预设装饰 | 基线 |
| B 可生成不持久 | 能生成，回访不保证 | 若 B 留存低于 A，说明「能生成但对不上」比没有更差（题眼） |
| C 生成+持久+可再编辑 | 完整命门 | C 显著优于 A 且优于 B，才值得加码小岛经营 |

观察：7 日留存、单次时长、回访弃玩率、不一致报告率。  
放量 5%→20%→50%，每档至少观察一个完整回访周期（建议 ≥7 天）。监控持久化率、延迟、可用性。

### 3.3 人工（持续）

- 每周抽样 ≥200 条生成，双人评符合度与「是否还是同一物」。  
- 每周 5–10 人走「生成 → 离开 → 回访 → 再编辑」。  
- 灰度期访谈 10–15 人：回访信任、还想不想改、NPC 是否像记得自己。

## 四、分阶段投入决策（值不值得继续）

能力验证路径与投入阶段合一，避免两套梯子。

| 阶段 | 玩法形态 | 进入条件 | 验证目标 | 继续加码 | 停止 / 转向 |
|---|---|---|---|---|---|
| **0-A 生成可行性** | AI 躲猫猫等**单局** | 创意过审 | 实时生成、单局内稳定、延迟可玩 | 成功率/延迟/单局符合度达标 | 生成能力本身不行 → **停**，不必做持久化 |
| **0-B 命门可行性** | 单房间装扮：持久化 + 连续编辑 | 0-A 过 | 跨会话还在、位姿对、能接着改 | 持久化 ≥95%；10 轮编辑 ≥90%；泄漏=0 | 生成行但记不住/一改就崩 → **不要做小岛**，可转向派对/单局生成 |
| **1 内测** | 小岛子集（少量 NPC 事实记忆，经济仅叙事） | 0-B 过 | 玩家是否因「记得住」而回访 | 回访弃玩率 ≤10%；7 日留存 ≥25%；14 天无 P0 一致性事故；C 臂优于 A、B | 弃玩率 >20% 或 7 日 <15% → 玩家不买账，停完整形态 |
| **2 灰度** | 扩大岛与记忆 | 阶段 1 过 | 规模化稳定性 | 持久化 ≥99%；编辑累积 ≥95%；弃玩率 ≤5%；7 日 ≥35%；可用性达标 | P0 一致性事故或可用性崩溃 → **暂停放量并回滚**，不谈付费 |
| **3 全量后评估** | 完整经营（含单向 NPC 交易） | 阶段 2 过 | 长线是否值得继续砸运营/内容 | 30 日留存、NPS、经济观察项健康 | 长线留不住再评估方向；**此时才把付费当参考** |

**决策一句话：**

- 0-A 挂：不会生成，停。  
- 0-A 过、0-B 挂：会生成但世界无记忆，**本定位不成立**，转单局玩法。  
- 1 挂：技术够，玩家不信或不玩。  
- 2 挂：小范围可以，规模化不行，先修再放。  
- 3 差：玩法能上，长线生意另议。

## 五、回滚

**触发（任一）：**

- 持久化率连续 3 天 <95%  
- 回访弃玩率连续 3 天 >10%  
- P0：大范围物品丢失/世界崩坏，影响 ≥1% 活跃玩家  
- 生成服务连续 24h 可用性 <99.5%  
- （仅阶段 3 经济已上线时）金币 7 日增幅 >50% 且物品总量增幅 <20%

**动作：**

1. 停止新用户放量。  
2. 关闭实时生成，回退预设装饰（已写入物尽量保留）。  
3. 大规模崩坏则回滚最近一致快照，说明 + 补偿。  
4. 冻结 NPC 记忆更新，防止错记扩散。  
5. 不默认给所有物品打「请核对」吓人标签；仅对校验失败存档提示。

**修复后再上：** 24h 内定位（模型 / 状态存储 / 写入逻辑）→ 修数据 → **重跑阶段 0-A/0-B 全套离线** → 从 ≤1% 流量重灰。

## 六、加分摘要（完整框架见交付四）

交付三只保留与本岛评测直接咬合的复用要点；团队级五层体系、使用流程与「体验达标线」展开见 `04-可复用评估框架.md`。

对本岛而言，体验达标线里最尖、最容易被错抄的子项是 **一致性阈值**：

四层问题可复用到其他游戏向生成能力：

| 层 | 核心问题 | 通用指标 | 适用 |
|---|---|---|---|
| 生成 | 能不能造、好不好、够不够快 | 成功率、延迟、符合度、幻觉 | 一切生成玩法 |
| 世界合法性 | 不该变的是否还在；该变的是否有规则 | 持久化、多轮操作累积一致、门禁泄漏、演化可解释 | 要持续世界的品类 |
| 体验 | 爱不爱用、信不信 | 弃玩率、留存、报告率、确认/编辑组合 | 一切玩家向功能 |
| 投入 | 是否加码 | 分阶段门槛；商业指标后置 | 一切立项 |

**最难复用的是一致性阈值，必须按品类重标定，禁止照抄本岛 95%/99%：**

- 沙盒经营（本创意）：跨局持久近乎硬性，回访即考场。  
- RPG：关键道具/剧情节点高，过场细节可松。  
- 单局派对（躲猫猫）：局内一致即可，**这正是 0-A 成本低的原因**。

复用时同时重做：**「离开」如何操作化、容差、允许演变清单**。换品类不换这三件，指标会假阳性。

## 七、与 Demo / 交付一的接口

| 交付二 Demo 演示 | 本方案对应核验 |
|---|---|
| 预览确认才写入 | 未确认写入泄漏率 = 0 |
| 放置后离开再进灯还在 | 持久化率、位置准确率 |
| 改成玻璃风灯后主体仍在 | 连续编辑身份保持 + 编辑后回访 |
| 状态被破坏则提示恢复 | 快照回滚，不展示错乱世界 |
| NPC 提到这盏灯 | 世界事实记忆（脚本即可） |
| 不演示买卖 | 经济指标不进 Demo 验收 |

**灵魂三句：** 命门指标能量化；阶段 0 用躲猫猫/单房间把止损前置；商业数字不许提前否决「记不记得住」。
