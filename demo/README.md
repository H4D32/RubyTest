# 《我的AI小岛》交互 Demo

单页可点击演示：一致性闭环 + 连续编辑。

## 运行

```bash
cd demo
python3 -m http.server 8765
```

浏览器打开 `http://127.0.0.1:8765`。

## 推荐路径（约 4 分钟）

1. 接取小海委托  
2. 用矿石兑 1 个魔力瓶（2→3）  
3. AI 制作水母吊灯：生成 → 调整 → **确认采纳**（此时才扣瓶）  
4. 「按任务推荐」快速确认沙发、地毯  
5. 前往房间，拖拽到挂点并 **放在这里**  
6. 叫小海验收 → 离开一天后回访  
7. 点击吊灯编辑颜色/亮度 → 再离开一天验证  

生成为预设立绘模拟；状态保存在页面内存（离开按钮不重置）。
